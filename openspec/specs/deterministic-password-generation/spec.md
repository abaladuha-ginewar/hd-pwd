## Purpose

定义密码项 key、版本化确定性生成协议、密码规则、恢复配方与无密码库恢复，以及生成输入变更时的警告行为。

## Requirements

### Requirement: 密码项 key
系统 SHALL 要求每个密码项的 key 匹配正则表达式 `[A-Za-z_.-]+`、长度为 1 至 128 个字符，并在同一用户内按区分大小写的完整值保持唯一。key MUST 是参与密码生成的可变业务字段，而同步身份 MUST 使用独立且不可变的对象标识。

#### Scenario: 创建有效 key
- **WHEN** 用户提交符合格式且未被占用的 key
- **THEN** 系统允许保存密码项并保留 key 的原始大小写

#### Scenario: key 冲突或格式无效
- **WHEN** key 不符合格式、超过长度或与同一用户现有 key 完全相同
- **THEN** 系统拒绝保存并显示对应原因

### Requirement: 版本化确定性生成
系统 MUST 仅以恢复密码、区分大小写的 key、规范化密码规则和生成算法版本作为子密码生成输入。相同输入在 Android、Windows 和 Web 上 MUST 产生逐字节相同的结果，标题、标签、目录和颜色 MUST NOT 影响结果。

#### Scenario: 跨平台生成
- **WHEN** 三个平台使用同一恢复密码、key、规则和算法版本
- **THEN** 系统生成完全相同的子密码

#### Scenario: 生成输入变化
- **WHEN** key、规则、恢复密码或算法版本中的任意一项变化
- **THEN** 系统将其视为新的生成输入并产生相应的确定性结果

### Requirement: 稳定可扩展的生成协议
系统 SHALL 为生成协议提供永久兼容的 V1 版本、规范化输入编码、固定 KDF 参数、域隔离和无偏字符映射，并通过固定测试向量约束所有平台实现。未来版本 MUST 以新版本标识并存，不得改变 V1 的任何输出。

#### Scenario: 应用升级
- **WHEN** 用户升级到支持更新生成算法的应用版本并打开 V1 密码项
- **THEN** 系统仍使用原 V1 协议生成与升级前完全相同的密码

#### Scenario: 字符选择
- **WHEN** 生成器将伪随机数据映射到非二次幂长度的字符集合
- **THEN** 系统使用拒绝采样或等价无偏算法，且不使用简单取模造成分布偏差

### Requirement: 密码规则
系统 SHALL 支持长度、允许及必须包含大写字母、小写字母、数字和符号、每类最少数量、可用符号集合以及可选排除字符。系统 MUST 在保存前验证规则可满足，并默认使用长度 20、每类至少一个字符及符号集合 `!@#$%^&*_-+=.?`。

#### Scenario: 使用默认规则
- **WHEN** 用户创建密码项且不修改密码规则
- **THEN** 系统采用默认长度、默认符号集合并保证大小写字母、数字和符号各至少一个

#### Scenario: 规则不可满足
- **WHEN** 密码长度小于所有必选字符最少数量之和或允许字符集合为空
- **THEN** 系统拒绝保存规则并指出冲突约束

### Requirement: 子密码不持久化
系统 MUST NOT 将生成后的子密码写入密码库、备份、同步事件、日志或长期内存缓存。系统 SHALL 仅在显示、复制或显式恢复操作期间临时生成子密码。

#### Scenario: 保存密码项
- **WHEN** 用户创建或编辑密码项
- **THEN** 系统只保存 key、规则、版本和展示元数据，不保存生成结果

### Requirement: 恢复配方
系统 SHALL 为每个密码项生成可复制、可校验且版本化的恢复配方，配方 MUST 包含 key、完整规范化规则、生成算法版本、格式版本和校验码，但 MUST NOT 包含恢复密码、用户名、标题、标签或生成后的子密码。

#### Scenario: 复制恢复配方
- **WHEN** 用户点击复制恢复配方
- **THEN** 系统复制带格式前缀、Base64URL 规范化载荷和校验码的完整配方

#### Scenario: 配方被破坏
- **WHEN** 用户粘贴的恢复配方不能通过格式或校验码验证
- **THEN** 系统拒绝生成并提示配方无效

### Requirement: 无密码库恢复
系统 SHALL 提供无需现有用户密码库的恢复入口，允许用户输入恢复密码并粘贴恢复配方或手动输入相同 key 与规则来重建子密码。

#### Scenario: 使用完整配方恢复
- **WHEN** 用户提供正确恢复密码和有效恢复配方
- **THEN** 系统按配方指定版本重建对应子密码且不要求读取备份

### Requirement: 生成输入变更警告
系统 SHALL 在编辑 key、密码规则或算法版本时明确提示生成结果将改变，并在保存后使旧恢复配方失效。

#### Scenario: 修改 key
- **WHEN** 用户修改现有密码项的 key 并尝试保存
- **THEN** 系统显示密码变化警告，确认后保存新输入并提供新的恢复配方
